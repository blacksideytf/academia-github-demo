# Política mínima de uso · Claude + GitHub (plantilla)

- [ ] La app de Claude solo está en los repos de la lista del runbook.
- [ ] `main` está protegida: pull request obligatorio y una aprobación humana.
- [ ] Las claves de Claude están en los Secrets de la organización.
- [ ] Nadie pega claves en issues, pull requests, chats ni YAML.
- [ ] Los workflows llevan `--max-turns` y `timeout-minutes`.
- [ ] Code Review tiene un límite de gasto mensual.
- [ ] Revisión mensual: quién tiene acceso, qué repos y cuánto se gastó.
- [ ] Si se filtra una clave: revocar y rotar primero, investigar después.
